FAQ

Frequently Asked Questions

Is this a real robotics company?
No! This is a student academic project created for the ETEC de Hortolandia Open Doors 2026 event. We are high school technical course students, not a company. The website was built as an interdisciplinary assignment combining Web Programming and English Language classes.
Will my form submission actually reach the team?
The contact form demonstrates HTML5 and JavaScript form validation — a key learning objective of the project. For the academic demonstration, submissions are validated and confirmed client-side. This is intentional: the project showcases front-end development skills.
Can I reuse the content or code from this website?
The content is protected as an academic work. The code structure (HTML/CSS/JS patterns) is available for educational reference. If you are a student looking for examples, feel free to study it, but please do not copy it wholesale for your own academic submission — that would be plagiarism.
Why is the website available in both Portuguese and English?
The project is interdisciplinary, combining both Web Programming I (PWI) and English Language classes. Creating a fully bilingual website was one of the core requirements, allowing us to practice both technical web development and foreign language skills simultaneously.
