About the Project

Technical and institutional information about how this project was built and what technologies were used.

School & Event
  • ETEC de Hortolandia
  • Open Doors (Portas Abertas) 2026
  • Theme 4 — Robotics and its applications in today world
  • Team: Matheus S., Paulo, Lucas, V. Souza
  • Advisors: Profa. Celia Barufaldi & Prof. Waldir Junior
  • Year: 2026
Technologies Used
  • Semantic HTML5 with ARIA accessibility attributes
  • External CSS3 with custom properties (css/style.css)
  • External JavaScript with form validation (js/script.js)
  • Bootstrap 5.3 via CDN for responsive grid
  • Font Awesome 6.4 via CDN for icons
  • AOS 2.3 (Animate On Scroll) via CDN
  • Google Fonts: Inter (300-900 weights)

DID YOU KNOW?

This project was developed as an interdisciplinary assignment for Web Programming I (PWI) and English Language classes, combining web development skills with foreign language proficiency. Building a fully bilingual website from scratch required the team to think about information architecture, translation quality, cultural adaptation, and technical implementation all at the same time — a true 21st-century learning challenge!
